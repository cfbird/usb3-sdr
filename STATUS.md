# usb3-sdr: status and next steps (saved 2026-10-26)

`collab` (see ~/collab/PROTOCOL.md). AGY verdicts and Claude's checks: notes/review_claude_of_math.md.

## Regenerate / verify
```
cd kicad/gen && ./make_all.sh      # schematic → verify (203/203 nets) → LPF check (71/71) → ERC → PCB → DRC
cd gateware && make && make sim    # bitstream + DDC / FT601 / boot sims
```
Note: make_all.sh rebuilds the PCB placement from scratch, so stop using it once you hand-edit or import a routed board.

## State (2026-10-26)
- Schematic: ERC 2 expected violations (USB3 RX pair driven by the host). Netlist 203/203, LPF 71/71.
- FPGA ball map re-assigned so the FT601 and ADC buses are planar; LPF, schematic and board synced; nextpnr passes.
- Gateware: FT601 outputs and tristates in IO registers on a +112.5 deg PLL clock; AD9649 DCO inverted at boot
  (reg 0x16 = 0x80); all sims pass.
- **Work board fully routed: 0 unconnected, schematic parity 0, copper clean, no dangling copper** (left: the 10
  inherent SMA edge-clearance items and silk warnings). 8 single-layer vias and 3 loose stubs removed 2026-10-26

  FT601 11.2-28.5 mm). Its one FAIL, FT_SIWU_N, is a checker name mismatch (the net is FT_SIWU, routed).

- In2 rectangle x 134-152, y 108-134 is now GND (was a 1V8_A zone with no loads, left from an earlier ADC position;
  kicad/gen/pcb_build.py still draws it as 1V8_A).
- FT601 centre pad has 7 GND vias (0.2 mm drill). Seven ADC nets run at 0.10 mm width / 0.13 mm gap (min 0.09).
