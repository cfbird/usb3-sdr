# usb3-sdr: status and next steps (saved 2026-10-24)

USB3 direct-sampling HF SDR: AD9649 (14b 80 MSPS) → ECP5 LFE5U-25F (DDC) → FT601 → USB 3. Built with AGY via
`collab` (see ~/collab/PROTOCOL.md). AGY verdicts and Claude's checks: notes/review_claude_of_math.md.

## Where everything is
| Path | What |

## Regenerate / verify
```
cd kicad/gen && ./make_all.sh      # schematic → verify (203/203 nets) → LPF check (71/71) → ERC → PCB → DRC
cd gateware && make && make sim    # bitstream + DDC / FT601 / boot sims
```
Note: make_all.sh rebuilds the PCB placement from scratch, so stop using it once you hand-edit or import a routed board.

## State (2026-10-24)
- Schematic: ERC 2 expected violations (USB3 RX pair driven by the host). Netlist 203/203, LPF 71/71.
- FPGA ball map re-assigned so the FT601 and ADC buses are planar (crossings 237 -> 0 and 60 -> 0); LPF, schematic and
  board synced; nextpnr passes.
- Gateware: FT601 outputs and tristates now in IO registers on a +112.5 deg PLL clock (fixes the T4 hold problem);
  AD9649 DCO inverted at boot (reg 0x16 = 0x80); all sims pass.
- ADC sample clock laid out on F.Cu (polarity swapped on purpose). BOM U9 corrected.
- Work board DRC: only the inherent SMA edge-clearance items, 3 dangling stubs, 104 unconnected (mostly the two buses);
  schematic parity 0.
- Bus routing is blocked by power copper and passives in the BGA escape area. A fan-out re-plan (new In2 islands, core
  vias, decap moves) is being iterated with AGY; trials run on throw-away copies via kicad/gen/fanout_trial.py.
